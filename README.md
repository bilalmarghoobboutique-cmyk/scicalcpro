# SciCalcPro — Scientific Calculator

The fastest, most beautiful, multi-language scientific calculator on the internet.

## Brand
**Bilal Marghoob Creations**

## Features
- 100% Scientific Calculator (40+ functions)
- 10 Languages (English, Urdu, Punjabi, Hindi, Arabic, Spanish, French, German, Chinese, Russian)
- AI Chatbot: Math Tutor ("Ask the question about maths")
- User Login / Signup
- Like & Comment System
- Admin Dashboard (12 sections)
- PWA (Installable Mobile App)
- 100% Free Hosting

## Tech Stack
- Frontend: HTML, Tailwind CSS, Vanilla JS, Math.js, Vite, i18next
- Backend: Node.js, Express, MongoDB, JWT
- Hosting: Vercel (frontend), Render (backend), MongoDB Atlas (database)
